I'm a **computer engineer with a Master's in Cybersecurity**, currently working full-time
as a **Penetration Tester at ONE eSecurity**. Before going full offense, I spent time on
the defensive side as a **Network Security Engineer at BBVA** — which means I've sat on
both sides of the firewall, and I know exactly what blue teams look for when I'm trying
not to get caught.

- 🔓 Full-time **pentester**: web apps, infrastructure, Active Directory, and macOS red-teaming
- 🍎 Deep focus on **macOS offensive security** — discovered **Floro**, a zero-day vulnerability in macOS
- 🛠️ Building **MacHawkEye**, a tool for identifying macOS binaries susceptible to exploitation and developing 1-day exploits against them
- 🧠 Keep a growing personal knowledge vault (**"Pentra"**) of pentesting methodology, AD attack paths, and red-team tradecraft
- 🤖 Building an **AI-assisted Red Team Agent** — an LLM-orchestrated recon/exploitation copilot wrapping nmap, httpx, nuclei, and CVE intel
- 💸 Long-term goal: ship security tooling that pays for itself (passive income via products, not just billable hours)
